# 残響のアルカディア（仮）

ファミコン時代のコマンド式 RPG を目指す Rust プロジェクトです。最初の章「帰らなかった灯」では、アレンとリリスが旧水門の異変を解決し、ノクスに残る忘却戦役の救助記録を追います。[全編のあらすじとノクス編](docs/main-story.md)

## 遊び方

矢印キーまたは WASD で移動し、Enter、Space、Z で決定します。J でアレンの手記を開き、Esc または J で閉じます。スマートフォンでは横向きにすると大きく表示できます。半透明の丸いタッチボタンで操作し、「操作を画面の外へ」で十字キーと決定などをゲーム画面の脇（縦向きでは下）に移せます。「操作を画面に戻す」で重ねる表示に戻ります。

案内精霊が示す場所で決定すると会話や調査を始めます。炉では体力を回復できます。戦闘では上下でコマンドを選びます。刻印魔法は大きなダメージを与え、手記の思い出を一つ失います。精霊共鳴は石碑での共闘から使えます。

## ワールドマップ

タイトル画面、フィールド探索中、序章クリア画面で M を押すと、環状列島ヴェルデリアの全体図を開けます。矢印キーや WASD で島を選び、Enter、Space、Z で上陸します。ブラウザのタッチ端末では「地図」「決定」を使えます。

上陸すると、その島の港から 312×192 タイルのフィールドを歩けます。探索中はキャラクターを大きく表示し、カメラが移動に追従します。標準の表示範囲は13×7タイルで、ブラウザの横向き表示では画面幅に合わせて左右に広がります。各島では魔導列車が線路を、馬車が街道を行き交います。五つの島それぞれに、港町を含む街・村が10か所、廃村・廃墟が3か所あります。それぞれ専用の複数タイルにまたがるアイコンで表示し、入口の目印まで歩くと名前と説明が表示されます。M または Esc で全体図へ戻れます。ノクス以外の港では決定キーでも全体図へ戻り、次の島を選べます。各島の野生動物10種・魔獣5種は島ごとに異なります。動物115匹と魔獣20体が、沿岸部や内陸の生息地の近くを歩き回ります。魔獣に近づいて「戦う」が表示されたときは、決定キーで戦闘を始められます。

### ノクスの街

ノクスでは街・村・港町の入口で決定すると、312×192タイルの徒歩マップに入れます。主要施設の近くで決定すると、会話・調査を選べます。J（手記）で街の略図と5本の依頼を確認し、上下キーで追う依頼を切り替えます。M / Esc、または入口の「島街道への出口」で島へ戻れます。霧灯の港町から出港するには、南の通船桟橋で「出港して全体図へ」を選びます。荷揚げ桟橋か救難艇庫で潮を待つと、引き潮の間だけ浜の近道を歩けます。

依頼の進行と結末はプレイ中に保持されます。舞台と物語は [街の設定資料](docs/settlements.md) と [サイドストーリー集](docs/side-stories.md) を参照してください。

## 案内精霊

序章とノクスでは、案内精霊が次のイベントに向かう道の数歩先に浮かびます。精霊を追うと、壁や水路を避けて目的地へ着けます。ノクスの島フィールドでは依頼が残る集落の入口を示し、街では手記（J）で選んだ依頼の会話や調査場所を示します。解決後は次に進める依頼を案内します。

## デバッグモード

タイトル画面で十字キーを **↑ ↑ ↓ ↓ ← → ← →** の順に押し、最後に決定します。キーボードの矢印キー、ブラウザの画面上の十字ボタン、対応ゲームパッドの十字キーを使えます。ゲームパッドの A が決定、B が戻るです。

五島の街・村・廃墟、ノクスのサイドストーリーの各段階、序章のイベントと戦闘へ直接移動できます。ノクスの街は内部の徒歩マップへ、島フィールド上の拠点は入口へ移動します。試遊を切り替えるたびにゲーム状態は初期化されます。Esc / B で戻ります。ブラウザではメニューの「戻る」ボタンも使えます。

## Windows

Rust と MSVC ビルド環境で実行します。

```powershell
cargo run --locked --release --bin yyquest-win
```

## WebAssembly

Rust と Node.js を使います。ローカル配信の例は Python を使用します。

```powershell
rustup target add wasm32-unknown-unknown
node tools/build.mjs
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

[ローカルのゲーム画面](http://127.0.0.1:8765/)を開きます。タイトル画面の「キャッシュを消して再読み込み」で、ブラウザ版のゲームファイルを取り直せます。

## Cloudflare

[YYDungeon の公開手順](https://github.com/ykwyuta/YYDungeon#cloudflare-配信)と同様、Cloudflare Workers の Static Assets で `dist` を配信します。Workers の Git 連携ではリポジトリ直下をルートに設定し、デプロイコマンドを `npx wrangler deploy` にします。`wrangler.toml` に指定した `bash build.sh` が `dist` を生成します。Pages を使う場合はビルドコマンドを `bash build.sh`、出力先を `dist` にします。

## 実装と素材

ノクスでは素材を採集し、調薬・売買・ドワーフ鍛冶ができます。島フィールドでは J（スマホは「手記」）で荷袋を開き、回復薬を使ったり武具を装備したりできます。[アイテム・貨幣経済の設計と入手先](docs/items-and-economy.md)

ゲーム進行と 640×480 の画面描画は Windows と WebAssembly で共有します。座標には 320×240 の論理解像度を使います。Windows は Win32/GDI、ブラウザは Canvas 2D に描画します。キャラクターと敵の素材の出典は [assets/README.md](assets/README.md) を参照してください。

```powershell
cargo test --locked --lib
node tools/build.mjs
node tools/wasm-smoke.mjs
```
