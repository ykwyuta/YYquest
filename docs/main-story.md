# 残響のアルカディア メインストーリー

## 全編のあらすじ

新聖律歴30年。忘却戦役を終わらせた禁呪は、列島を救った事実と、そのために払われた代償を歴史から消した。ノクスの灰灯りの村で育ったアレン・ヴァイスは、父ガウェインの形見の剣を使って村の水門を開き、森で出会った精霊使いリリスと、戦役期の救助信号を聞く。アレンは父が守ったものを、リリスは自分を名前で呼ぶ声の主を捜す。

セレスティアでは、元審問官カインと聖堂の写本を突き合わせ、攻略記録として保存された帳面に避難民の証言が隠されていたと知る。国を率いるヴァレリウスは、戦役を忘れた列島が同じ過ちを繰り返すことを恐れ、七つの調律器で列島の全記憶を公的な一冊へ固定しようとしている。閲覧を禁じられた私的な記憶も対象となる。秘密を暴かない誓いを持つ巡礼神官ミナは、記録を残したいカインと衝突しながら、証言者が自ら公開の範囲を決める場を作る。

リベルタでは、フィーネの兄の航海日誌を取り戻すため、海賊船と港の自治会の双方に話を通す。兄が残した潮位と灯火の記録から、虚無の海に船で入れる時刻が分かる。ヴァルカンでは、元技師ガルダが、封印の継ぎ直しを名目に人から記憶を抜く装置の設計に加担していたと告白する。一行は工区の職工から協力を得て装置を解体し、記憶の代わりに各地で採った音を同時に届けるための共鳴機を組み上げる。

シルヴァの古根の封門で、リリスは自分が七英雄の一人であり、封印後にヴァレリウスが戦役の記憶を彼女に託したと知る。記憶を開けば封印の構造が分かるが、彼女自身がいま持つ記憶を圧迫する。リリスは他の仲間と記録を分担し、自分が何を見て何を話すかを選ぶ。アレンの剣にある削り跡は、バルドとヴァレリウスが互いの名前を刻み合った印だった。

虚無の海の神殿では、封印のほころびから目覚めるアビス・ロードと、すべてを一つの記憶に固定しようとするヴァレリウスに対峙する。各島の仲間が本人の同意のある記録を順に読み、共鳴機が七つの調律器へ同時に届ける。ノクスの三灯が最初の合図になる。封印を支える声を列島全体で担い、術者一人の記憶を燃やす負担を解く。エピローグでは、アレンが父の救助を記した板の隣に、いま村を支える炉番たちの名前を加える。リリスは自分で書いた旅の日付を手記の最初のページに置く。

## 第一章 ノクス「帰らなかった灯」

### 灰灯りの村と森の旧水門

早朝、村の水路が止まる。炉番は東の森から笛を聞き、アレンに父の剣を持たせる。ガウェインは刃の根元を旧水門の留め具として使っていた。父が留め具に何を刻んだか、炉番には思い出せない。

森で会うリリスは、止まった水路の下流に集まる精霊から、村の井戸が枯れかけていると聞いた。彼女は自分の名しかはっきり覚えていないが、笛で水門に残る水の音を呼べる。アレンが剣で留め具を外し、リリスが門を支える。開口部から出た霧のスライムをアレンが追い払う間、リリスは門を閉じさせない。これが二人の最初の協力になる。

水が戻ると、剣の根元が三回鳴り、北の石碑が同じ音を返す。リリスは先に碑へ向かう。忘却の獣が碑の残響を覆った場面では、アレンは正面を受け持ち、リリスは精霊共鳴でその霧を裂く。戦いの後、二人は、ガウェインが三つの灯で救助船を呼んだ夜を目撃する。碑の声はリリスを名前で呼んだ。アレンは父が砦に残った理由を知りたいと話し、リリスは自分を知る声を追いたいと答える。同行の約束を交わしたあと、二人で炉番に水門が戻ったことを報告する。

西風の砦町と谷守の村では、警備と生活のどちらを優先すべきかというバルドの判断が、現在の住民にも続いていると分かる。オオ麦の里と遠火の宿場は救助船や夜便を支える補給の現場、葦渡りの村は水門の前後で暮らし方が異なる例となる。灰石の市の拾得物の依頼では、物証の持ち主と町が保存したいものの違いに触れる。これらは既存のサイドストーリーから遊べる。

## チュートリアルで伝える操作

- 最初に炉番のいるタイルへ移動して決定する。以降の会話・調査も決定で始まる。案内精霊は次の場所へ導く。
- 旧水門の戦闘では通常攻撃と防御を試せる。刻印魔法は強力だが記憶が減り、手記で失った記憶が分かる。
- 石碑では一時的にリリスの精霊共鳴が選べる。戦闘上の協力を体験してから、二人が同行を決める。
- チュートリアルの戦闘で倒れた場合は調査地点に戻り、戦闘前の記憶と体力で再挑戦できる。
- ノクス本編では、目的地の操作メニューの先頭に章のイベントが現れる。手記で別の依頼を選んだ場合は、その依頼へ案内が切り替わる。
