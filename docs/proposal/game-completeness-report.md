# 『残響のアルカディア』ゲーム完成度レポート

対象は 2026年11月16日時点の `1096a37`。実装と全編の構想を照合し、第一章を独立した体験版として遊ぶ場合と、全編を遊ぶ場合の両方を評価した。確認後に作業ツリーで進み始めた採集の変更は評価対象外。 [README](../../README.md) · [全編のあらすじ](../main-story.md)

## 総評

**第一章は、ニューゲームから章の結末まで遊べる。体験版としての優先課題は、移動・調査・戦闘・育成を章の山場で結び、途中から再開できるようにすること。** 旧水門と石碑では、操作を覚える過程そのものが、アレンとリリスが協力して旅に出る理由になっている。ノクスに移ると、主筋は長い移動と六つの会話・調査で進み、最後の天墜ち砦跡も入口で記録を読む場面にとどまる。素材、装備、魔獣、依頼は揃っているため、章を終えるまでにその面白さを体験できる導線が足りない。 [序章と戦闘](../../src/game.rs) · [ノクスの六段階](../../src/campaign.rs) · [廃砦の調査](../../src/world_map.rs)

**全編としては、物語が列島の広さに追いついていない。** セレスティア、リベルタ、ヴァルカン、シルヴァには上陸して魔獣と戦えるが、街の内部と本編はノクスに限られる。第一章終了画面の「次の航路へ」で地図を開き、セレスティアに上陸しても聖堂の事件は始まらない。虚無の海は地図に表示される段階で、神殿での決着とエピローグは構想にある。 [第一章終了画面](../../src/render.rs) · [上陸・入町処理](../../src/world_map.rs) · [全編のあらすじ](../main-story.md)

## 優先順位と完了条件

1. **第一章に区切りを付けて公開できる状態にする。** 進行保存と「つづきから」を用意し、章・依頼の進行、装備・所持品・銀環、HPと記憶、初討伐報酬の取得状態を復元する。ニューゲームから通常の操作で章を進め、途中で終了・再開しても依頼の結末や報酬が変わらず、「第一章　ノクス　完」まで到達できることを確認する。第一章を体験版として公開する場合は、章の終わりと、その先で遊べる範囲をゲーム内で伝える。
2. **天墜ち砦跡をノクス編の山場にする。** たとえば三灯と拓本の手がかりを使って砦内で進路を開き、リリスとの共闘で刻印魔法・精霊共鳴・防御の使い所が分かる対決を置く。道中で調薬や鍛冶を紹介し、初期装備でも突破でき、任意の準備は被害や手数に表れる形にする。砦の選択と戦闘の結果を港での報告につなげる。初見試遊では、攻略情報やデバッグ移動を使わず次の目的地を見つけられるか、移動と操作が間延びする区間はどこかを確かめる。
3. **セレスティアに着いた直後から次章を遊べるようにする。** 白帆港町から聖堂の写本調査とカイン・ミナの出会いにつないで、証言の公開範囲をめぐる章内の決着までを先に通す。その仕組みを残りの島にも展開し、各章で得る協力や記録を虚無の海の決着とエピローグに結び付ける。既に設定のある全拠点を埋める前に、ニューゲームからエンディングまで通る主筋を優先する。 [全編のあらすじ](../main-story.md) · [街ごとの設定](../settlements.md)
