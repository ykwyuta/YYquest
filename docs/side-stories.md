# 残響のアルカディア 街のサイドストーリー

[街の設定資料](settlements.md)に沿った、新聖律歴30年のサイドストーリー案。五島の街・村・港町50か所に各5本、全250本を配置する。各話の見出しは依頼や事件が始まる街を示す。本文に発端、歩いて調べる場所や相手、達成条件と解決後の変化を記す。

各街の第1話は、統治制度や生業に関わる問題を扱う。残る4話は、住民個人の願い、街の習慣、動物や魔獣、精霊などを題材にした独立した話。複数の結果がある話では、変化する通行、仕事、住民との関係などを結末に使う。

## 黄昏の辺境領ノクス

### 灰灯りの村

1. **炉の名札**　共同炉で薪札のない避難民を見かける。薪道で夜番の働きを確かめ、寄合に匿名の労働記録を出せば炉番の席を得られる。本人が望むなら名を届けて配給も受けられる。
2. **父の手袋**　旧宅の隣人から片方だけの手袋を預かる。ガウェインが繕いを頼んだ相手を訪ねると、戦の話よりも息子を初めて雪遊びに連れ出した日の話を聞ける。
3. **煙を追う**　冬越し小屋の煙が床下に戻り、夜中に皆が外へ出る。煙突の曲がりを外と屋根裏から確かめ、炉を止めて壁を直すか、薪割り場に仮の暖房を移して朝まで持たせる。
4. **薪山の番人**　薪割り場から毎晩束が一つ消える。積雪の足跡を追うと、幼い者が村外れの行き倒れを温めている。薪を届ける当番を決めるか、その人を小屋へ迎えるために敷物を運ぶ。
5. **灰の中の晩餐**　共同炉の炊事番が、誰も作り方を覚えていない宴の料理を再現したがる。古い鍋の焦げ跡と二人の異なる証言から一皿を選ぶと、出来上がった味に応じて食卓に来る者が変わる。

### 霧灯の港町

1. **最後の一缶**　油蔵で灯油の底が見える。信号台から今夜の霧と船影を確認し、灯を明け方まで絞るか、点灯を続けて救難艇の分を近くの船から借りる。
2. **折り返さない舟**　引退した船頭が、台帳にない帰港を覚えている。干潮の舟揚げ場で船名が刻まれた舵を回収すると、待ち続けた家族に上陸の事実を伝えられる。本人の行き先は浜で出会った証人が知る。
3. **霧笛の届く家**　灯台守が霧笛の苦情を三軒から受ける。聞こえ方を浜と崖で調べ、笛の向きを直して沖にも届くようにするか、住宅側だけに響く壁を外す。
4. **潮だまりの客**　救難艇庫の子が、潮だまりに増えた生き物を見に行けない。引き潮に同行して、捨て網に残された幼い海獣をほどき、外海へ戻る流れまで案内する。
5. **まだ借りられる桟橋**　荷揚げ帰りに、家族の葬送船と商船が同じ桟橋を予約していると知る。荒波でも使える場所を確かめ、漁師から小桟橋を借りるか、商船の荷を分けて時刻を調整する。

### 西風の砦町

1. **二枚の地図**　市の小商人が護送料の値上げに困る。観測櫓と柵外の放牧地を歩いて迂回図の欠点を示し、旧荷道を昼だけ開く案か、護送を共同購入する案を寄合に持ち込む。
2. **鐘が二度鳴る**　夜の見張りが、打っていない二度目の鐘を聞く。荒野の岩が反響を返す位置を突き止めると、魔獣警報だと思って逃げていた荷運び人を連れ戻せる。
3. **柵の内側で育つ**　門で親子の荷馬が検査に止められる。獣医役を呼び、病気と疑われた震えが輸送疲れだと分かれば、南の避難柵を一夜だけ借りられる。
4. **帳面を持った賊**　護送団が盗賊から取り返した荷に市の封印がない。支払控えを突き合わせると、襲った者も荷主も以前の護送賃を請求している。公開審理か、返還と分割払いの協議へ進める。
5. **最後の矢羽**　工房の元弓兵が引退試合の相手を探す。商人と若い門兵に声をかけ、的射ちか強風の距離当てを選ぶと、武芸と荒野での風の読み方のどちらを後継に伝えるかが決まる。

### 葦渡りの村

1. **二つの水位**　下流の漁師に頼まれ、潮位板と水門の目盛りを同じ時刻に読む。舟大工の古い流路図を使い、浚渫の土で塞がった脇水路を開けば、葦刈りと産卵期の水位を両立できる。
2. **渡し舟の輪番**　渡し守が手を痛め、夜の便が止まる。板道で乗客を案内して必要な便数を聞き、漁師に当番を頼むか、舟の昇降口を変えて片手でも扱えるようにする。
3. **杭に咲く花**　板道を直す若者が、取り替える杭に花を添える老女と出会う。花の位置をたどると水没した家の間取りになる。杭を替える前に、間取りを写して新しい板に刻む。
4. **籠をさらう風**　葦細工の籠が水路へ次々と落ちる。流れを追って引き上げた籠を持ち主へ返し、積み方を考えた子と重しを作って次の風の日に試す。
5. **板の下の産声**　夜の板道で鳴き声を聞いた住民が魔獣を恐れる。渡し舟で下からのぞくと、増水で取り残された仔獣がいる。道を一時閉じて親を待つか、魚棚から離れた浅瀬へ誘導する。

### オオ麦の里

1. **種蔵の秤**　供出の荷車が予定より重い。風車の控えと荷札から袋を選り分け、倉に来季の種を確保する。砦には不足理由を示し、古い粉を送るか別の里から借りる相談ができる。
2. **霜よけの夜**　畑の端だけ霜害を免れたと聞き、夕方の斜面で冷気の通り道を調べる。石垣を切り開く場所か藁で覆う列を選び、翌朝、生き残った苗を農家と数える。
3. **挽きたて一等賞**　帰郷した菓子焼きが市場に試食を並べる。粉挽きの粒度を変えて二種類の生地を作り、硬い保存菓子なら護送団、柔らかい菓子なら宿が次の買い手になる。
4. **止まらない風車**　風が落ちても軸が鳴り、粉挽きが祟りと噂される。梯子を登って制動具の摩耗を見つけ、手挽き番を集めて修理中の粉供給をつなぐ。
5. **畑の貸し手**　秋だけ耕地を借りた人が、来春の種貸しから外される。種蔵の貸出札と畦の作業を確かめ、畑主の保証で種を借りるか、一年目だけ共同試験畑を分ける。

### 石継ぎの町

1. **井戸底の戸口印**　井戸を閉める前に旧村の戸口印を写してほしいと頼まれる。石工の安全な迂回路で暗渠を進み、崩落前に原石を運び出すか、拓本だけ残して水路を早く塞ぐ。
2. **玄関の一段**　転用石を使った家の段差で足を悪くした老人が外出できない。古い石を残す斜路と低い敷石の案を職人に試してもらい、本人が歩ける形に仕上げる。
3. **石の雨漏り**　水番が毎回同じ壁の染みを拭いている。雨の日に石継ぎの裏道を歩くと、屋根の排水が隣家に回る仕組みを発見する。両家が使える樋を架けるか、水を路地の桶に集める。
4. **よその家の石**　新築の壁に、隣家が捜す家印入りの石が入っている。置場の札を調べ、壁を壊さず銘を見せるか、次の改築時に返す取り決めを結ぶ。
5. **石工の音当て**　若い弟子が見習いの試験で、石の割れを音から当てられない。工場と置場で同じ材を叩き比べて練習し、本番では使える面に切り替えて材料を無駄にしない案も選べる。

### 遠火の宿場

1. **夜便をつなぐ**　厩で、谷守に着く頃には診療所が閉まると聞く。旧飛脚道の番屋を使う乗継時刻を組み、馬方の夜番を頼むか、薬だけを徒歩で運ぶ小便を試す。
2. **火が見えない夜**　宿の灯を見失った飛脚が丘の向こうで朝を迎えた。風の当たる屋根と峠の視点を確かめ、灯の覆いを作るか途中の番屋に火を分ける。
3. **名前を持たない手紙**　宛名の抜けた封書が仕分け所で返送寸前になる。宛先の家を消印と紙の折り方から調べ、名前の出せない届け先への伝言を、受取人の了解を取って使う。
4. **替え馬の休み**　古い馬が長旅に耐えられなくなり、競りに回されそうになる。薬の受取人と厩番を引き合わせると、近い配達だけを担う仕事か谷の放牧地が見つかる。
5. **足音のすき間**　宿の子が夜を怖がり、旅人が悪く言われる。床下を調べて、空になった荷箱が風で転がる音だと突き止める。夕食時に実演すれば、子は次の夜の灯火当番に出られる。

### ノクス北門街

1. **二度帰った部隊**　旧詰番板の二つの日付について、門兵から内密に聞かれる。配給引換印と旗の補修年を調べ、徽章が後の部隊へ継がれた証拠を、遺族と守備隊の双方に示す。
2. **空き家の鍵**　配給列で同じ家の鍵を持つ二家族が出会う。水漏れと部屋数を見て、修理と引換えに共同で住めるようにするか、対面の空き室も開けるよう街区会へ願い出る。
3. **外濠の手すり**　古参兵が巡回する道で子が滑り落ちた。水位と巡回の足跡を確かめ、近道を閉じる代わりの門を探すか、避難にも使える手すりを住宅の職人に頼む。
4. **旗の裏の色**　門前の旗を繕う人が、布の継ぎ目に別の部隊色を見つける。家族の記憶を集め、元の布で一枚に戻すか、歴代の布を見せる旗の掛け方にする。
5. **配給所の朝番**　早朝の配給に夜警の家族や病人が並べない。受取札を代理人に渡す試行に立ち会うか、帰隊の時刻に合わせ夕方の窓口を設け、誰が初日を担えるか募る。

### 谷守の村

1. **荷の重さを分ける**　石荷を橋に通すと縄が危うい。北岸で荷を量り、沢道へ軽い分を回して診療客を先に渡すか、先に縄を交換できる石積み屋を探す。
2. **沢の子守歌**　診療所の患者が、赤子の頃に聞いた歌を思い出したがる。谷底の旧居跡と対岸の作業歌を比べると、二つを合わせた歌にたどり着き、歌い手を連れて帰れる。
3. **鐘を鳴らす人**　訓練日に無人側から避難鐘が鳴る。南北の聴取点を歩き、谷の風で鳴る綱を調べて固定する。住民が渡れない場合も鳴らせる補助綱を提案できる。
4. **廃屋の蜂**　沢道の旧家に巣を作った蜂を、石積みの人夫が追い払いたがる。谷の花を調べて巣箱を置けば、道を守りながら診療所は蜜を手に入れられる。
5. **対岸の診察券**　通院中の住民が渡橋の合間に忘れ物をする。診療所と橋守の間に往診の印を置くか、住民を迎えに来る付き添い当番を募り、次の診察日に試す。

### 灰石の市

1. **刻印を研ぎ落とす前に**　河原市で、元の持ち主を探す工具が研磨待ちになっている。荷運び人の控えと痕跡を照合し、遺族へ返すか、持ち主の同意で修理人に使い続けてもらう。
2. **鐘楼の遅刻**　買い付け人が、時計塔が二度違う時刻を指したと訴える。朝市と鍛冶の終業音で時計の狂い方を測り、歯止めを直して露店の開市時刻を揃える。
3. **一日の店主**　行商人が荷の引取に向かい、開市まで店を預ける。買い手の要望を聞き、値を下げて食器を売り切るか、取り置きを約束して常連との関係を守る。
4. **尋ね物は靴一足**　互いに別の靴だと思っている二人から片足ずつ集まる。靴底の縫いと河原のぬかるみを調べ、片方を直した元の職人へ二人を案内すると、靴の用途が一つに結び付く。
5. **鐘が止まった夕市**　時計塔の補修で夕方の取引を切り上げる話が出る。日暮れの広場を歩き、道が暗くなる露店を河原側へ移すか、研ぎ屋の明かりを借りていつもの場所を保つ。

## 聖律皇国セレスティア

### 白帆港町

1. **札のない巡礼者**　宿で足止めされた船客に会う。救難階段を上って灯台の番号札を確かめ、港務院の聞き直しに付き添うか、灯台守の許可で治療中の下船先を確保する。
2. **白崖の灯を磨く**　灯台の反射板を下ろすと船が寄れなくなる。浜で明かりを試し、引退した研磨職人の小鏡を仮設すれば、風待ちの一晩で板を直せる。
3. **荷札の絵葉書**　貨物検査で見つかった絵葉書を巡礼宿に届ける仕事を受ける。絵と同じ角度で崖の階段を見下ろすと隠れた待合が分かり、差出人の子に再会の伝言を渡せる。
4. **海へ落ちた鐘縄**　灯台の救難鐘の縄が切れた。磯に絡む縄を外し、余った綱を荷役人へ返すか、次の嵐に備えて短い予備縄を近くに結ぶ。
5. **小麦を積む場所**　大時化を前に穀物の仮置き場が足りない。港宿の一階を借りて宿泊客を上階へ案内するか、警備の見える税関裏に分散して夜番を募る。

### クロノス聖堂街

1. **奉納した覚えのない日**　家族相談所から聴聞に同行する。照合印の違いと奉納室の運用帳を調べ、証人の同意を得た証言で記録の訂正を求めるか、先に当事者の閲覧権だけを取り戻す。
2. **鐘のあいだの沈黙**　片方の鐘だけが休む刻に、双塔を訪れると鐘守が二人いたことを知る。塔の鐘刻をつなぐ調整をして、病の相棒に最後の合図を届ける。
3. **忘れてよい感謝**　巡礼者が恩人の記憶を奉納する前に手紙を書きたいという。西の相談所で代筆人を探し、恩人本人に渡すか、巡礼路の見知らぬ旅人を助ける品に添える。
4. **交代しない衛兵**　詰所前で交代時刻を過ぎても一人の兵が持ち場を離れない。元の配置図と隊の補修記録を探り、塞がれた階段にかつて事故があったと知る。通行止めを明示すれば兵は休める。
5. **広場にない献花台**　花を置く場所の撤去で、奉納を選ばない遺族が追悼できずにいる。広場の使われない早朝の場所を確かめて仮の台を設けるか、回廊脇を近隣の住民と整える。

### 白壁の砦町

1. **崖下に残す一杯**　井戸の水位が下がり、工兵が古坑を開けたがる。測量台で家屋直下を避ける線を見つけるか、軍用水槽の古い漏れを修理して追加取水を止める。
2. **白壁のつばめ**　砦壁の穴を塞ぐ前に、巣の持ち主を調べてほしいと子どもに頼まれる。水平階段から雛が巣立つ時期を見て、壁の補修を数日待つか、穴の外だけ養生する。
3. **階段番の椅子**　足の弱った防衛兵が階段の巡回を降りることになった。崖下の井戸と踊り場で必要な番人を探し、休める椅子を作れば、交代を待つ住民の相談係を続けられる。
4. **波が隠した境界**　演習中に流れ着いた標的を崖下の子が拾った。崖上の標柱と潮の流れを合わせ、演習の境を引き直すか、子どもの浜遊びを安全な時間に切り替える。
5. **壁に刻んだ渇き**　見習い工兵が貯水跡の線を美観のため削れと命じられる。古参から渇水時の節水手順を聞き、目盛りを公共井戸に移すか、砦壁の一部を記録として保存する。

### 麦穂の宿場

1. **列の外のパン**　北行きの粉袋が検問で止まる。倉の在庫を確かめ、朝市でパンと麦の現物交換を整えるか、検問側に腐りやすい粉だけ順を早めてもらう。
2. **挽かれない麦**　風車の弟子が小麦の香りの違いから袋違いに気づく。粉になる前に畑へ持ち帰り、まかれるはずだった在来の麦を取り戻す。
3. **布袋の帰路**　施食所に借りたままの布袋が溜まる。焼印の手がかりを辿り、袋を運び手に返して預り金を戻すか、買い付けに再利用する共用袋を作る。
4. **旅の食卓**　施食所で小麦が食べられない巡礼者に出会う。南の早市と宿の台所で豆や芋を集め、粉を使わずに旅に持てる一食を仕立てる。
5. **追い風の墨**　宿帳の落書きを巡って二人の子が揉める。風車の羽根の絵に重ねると昔の回転の記録になると分かり、一人一枚ずつ羽根の絵を描ける壁を宿主に借りる。

### 湖鏡の町

1. **水面が下がるあいだ**　旧記録庫の露出から次の満ち戻りまでに回収の順を決める。町の台帳棚と水に弱い私信箱では必要な人手が異なる。乾燥工房の空きと潜り手の安全が持ち帰れる量を決める。
2. **封のまま返す**　乾燥工房で拾った私信の名が二家族に当てはまる。封を開かず紋と便の控えを調べ、受取人の希望で読み上げるか、封をしたまま家に返す。
3. **晴れ間の屋根**　写本を乾かす日に雨雲が速いと水上組から聞く。屋根から順に回収し、屋内の吊り棚を増やすか、温めすぎず乾く風の道を探す。
4. **湖の底の鐘台**　渡し客が水中に屋根が見えると知らせる。舟から見える角度と旧湖岸の地図を比べ、沈んだ渡し場の柱を見つけ、漁師が網を破らないよう浮標を置く。
5. **同じ名前の家**　照合会に提出された写しの屋号が同じで、離れた二軒が一つに登録されている。別々の取水札と近所の証言を集めれば、両方の住人が渡し券を受け取れる。

### 鐘草の村

1. **谷へ届く三打**　時報の統一案を村が試したところ、水番が危険の合図を聞き逃す。谷の三地点を巡って安全の合図が聞こえる間隔を探し、時報を先にするか合図を別の鐘に移す。
2. **鋳物師の耳**　老いた鋳物師が新しい鐘の音を判断できなくなった。北の畑と水番小屋から聞いた感想を集め、弟子へ音見を継ぐ場を整える。
3. **薬草を焼く朝**　乾かしていた薬草が破れた干し棚から霧に落ちる。香りを頼りに畦を歩き、無事な袋を薬師に届け、濡れた分を入浴用として使えるか尋ねる。
4. **欠けた舌の帰還**　廃村から持ち帰った鐘の部品を巡り、鍛冶は再鋳造、遺族は保存を望む。古い音を響かせる台を試作し、部品を溶かす前に今の鐘との違いを聞けるようにする。
5. **牛が覚えた合図**　鐘を変えてから牛が畑へ入る。牛追いと観察してどの音で動くかを確かめ、鐘の試打時間をずらすか、餌場を移して新しい合図を教える。

### 聖律門の市

1. **通らない検印**　生鮮品が門外で傷み始める。証文屋ごとの控えと共同秤の記録を突き合わせ、偽印の混じる屋号だけ再検査にするか、負担の大きい荷を先に条件付きで開放する。
2. **最後の一枠**　共同秤の閉鎖まで二組が最後の計量を争う。魚の傷みと織物契約の期限をそれぞれ聞き、仲裁所の立会いで品を分けるか、次の朝に追加の枠を作る。
3. **門外の小机**　読み書きに不慣れな行商から、契約が読めず取引を失ったと聞く。仲裁人になり手を紹介して読み合わせの日を設ければ、門衛の再審査と買い付けの両方で証文が使える。
4. **秤が沈む日**　新しい秤の値が雨の日だけ軽くなる。屋根の漏れと共同秤の台座を調べ、受け皿の水を抜くだけか、水で軟らかくなる台ごと交換するか決める。
5. **売れ残った祝祭灯**　潰れた祭りの在庫を売れと露店主に頼まれる。巡礼宿の非常灯に回すか、門外市の夕食場に吊るして閉市後の客を呼び込む。

### 誓約の修道村

1. **誰に交わした誓い**　施療師と古参で誓いの言葉が違う。回廊で当時の避難経路をたどって証人を訪ね、今の患者への誓約を結び直すか、旧い誓いを続けつつ他の手当を募る。
2. **歩ける薬草園**　施療を終えた旅人が薬草番への礼に草取りを志願する。段畑の斜面を下る別経路を開いて、本人が届く畝で仕事を体験できるようにする。
3. **塀の外の皿**　隔離小屋へ届く食事に日ごとの菓子が添えられる。食器の印を手掛かりに回廊の料理番を探し、菓子と引き換えに旅人の故郷の味を試作する。
4. **余った寝台**　退院を控えた人が、空いた寝台を別の人へ使ってほしいと言う。宿では休めない事情を聞き、旅人用小屋を回復室にするか、村の炊事当番に通い看護を頼む。
5. **薬棚の元日**　先代が並べ替えを忘れた薬の棚で手が止まる。採取した斜面の札と、薬師の控えを照らし、札を文字順にするか、夜でも見分けられる手触りの印をつける。

### 段丘の集落

1. **泥水の出口**　下段の畑へ流れる泥水を工事前の排水跡から追う。工事側の沈殿溝を直すか、下段の水が戻るまで普請を止めるか、段会所で水番と協議する。
2. **ずれた測量柱**　石積みの直後に柱が一指ぶん傾いたと子どもが言う。畦道で隣の柱と水面を見比べ、崩れかけの小壁を田植え前に補強する。
3. **上下の郵便**　坂を上れない配達人が最上段への便を頼む。水運びの途中で届けられる家と階段の掛け箱を提案し、雨の日も手紙が濡れないようにする。
4. **湧き水の分け方**　用水を休ませたい段と、苗を植えたばかりの段が争う。溜め水の持ち時間を現地で調べ、時間をずらして取水するか、乾きやすい畝にだけ桶で運ぶ。
5. **棚田の鏡祭り**　田を空けて灯を映す祭りが、遅れた田植えと重なる。石段から映り方を調べ、空いている一段に灯をまとめるか、排水後の窪地を小さな水鏡にする。

### 巡礼坂の宿町

1. **証人の寝場所**　聴聞延期で円形宿が満員になる。空き倉庫をよそから見えにくい仮宿に整えるか、宿を分けて巡礼者の通りと証人の出入りをずらす。
2. **階段がつらい巡礼者**　坂下で座り込む旅人に声をかける。荷役坂の路面と踊り場の休憩点を調べ、車椅子を借りるか、背負い手に途中までの料金で協力を頼む。
3. **厨の方向音痴**　朝食を告げる円形宿の鐘が、廊下で部屋の奥から鳴るように聞こえる。音が強い箇所を歩いて調べ、食堂の開く方へ小さな案内灯を追加する。
4. **励ましの石段**　坂の途中の励まし文を刻んだ石が割れる。荷背負いの祖父から刻んだ理由を聞き、石を残して補強するか、言葉を次の踊り場へ移す。
5. **雨靴を返す日**　雨の日に宿から借りた靴が戻らず、次の客の足元が濡れる。坂下の待避舎や荷物庫に返却箱を試し、返しに宿まで上り直さなくても貸出を続けられるようにする。

## 深緑の樹海国シルヴァ

### 梢の集落

1. **裂けた枝の下**　吊橋を外す期限が来た。朝の地上を通って魔獣の営巣地を避ける道を測り、荷を地上に下ろすか、北の荷揚げ台から小分けに渡す準備をする。
2. **名残の橋名**　古い橋名が二本の道について混乱が起きる。成長した幹の傷をたどって元の橋脚を見つけ、失われた道の名前を片方の橋か広場に引き継ぐ。
3. **どんぐりの合図**　子が地上の友人に毎日どんぐりを落とすが、返事が絶える。小屋の屋根に上って鳥が溜め込む場所を探し、鳥の食料を残して子ども同士の合図を橋へ移す。
4. **夜に荷を上げる**　病人の寝台を夜の荷揚げ台で運びたいが、地上に夜行の魔獣が集まる。灯を抑えて合図だけで荷を上げるか、見張りが来る朝まで樹上の薬師に診てもらう。
5. **止まり木の柱**　梯子の上に珍しい鳥が来なくなる。見張り小屋から観察し、橋の鳴る継ぎ目を直して異変を解くと、鳥好きの住民が渡り鳥の季節を教えてくれる。

### 葉影の港村

1. **杭を打たない桟橋**　旅客船の増便で根を切る案が出る。潮見台で澪を読み、古杭を使った浮桟橋を試すか、大船から舟で客を運ぶ便を設ける。
2. **根を抱く舟**　嵐のあと水没した舟が根の間に挟まる。苗床の裏から根の動きを見て潮を待つか、舟大工に船板だけ外して回収できるか頼む。
3. **水面の種運び**　小魚に食べられる前に、潮で運ばれた種を苗床へ戻してほしいと頼まれる。入り江の航路を舟で回り、一部を野生に残す場所も選ぶ。
4. **潮に覚えられた歌**　仕事歌に応じる水音が干潮にだけ聞こえる。古杭で精霊共鳴を試すと、歌の節が浅瀬の目印だったと分かり、先代船番の航路を復元できる。
5. **船のない船大工**　手が震えるようになった老大工が工房を閉める。若い船番を集め、櫂作りの治具を工夫するか、修理箇所を診る役を新たに任せる。

### 根渡りの里

1. **根の上は誰のもの**　白い歩橋の修理代に通行料が提案される。上流の根を歩いて短い橋の位置を探すか、薬草商の資金で荷車だけから料金を取る案を検討する。
2. **根の向こうのおつかい**　増水で誕生日の品を渡せない子に会う。根と渡し場を回って対岸の子を探し、二人が会える岸辺を渡し守に聞く。
3. **橋板の葉模様**　寄進された古い橋板に、橋守の家では読めない葉の印がある。板材置場から西の木取り場へたどり、送り主の家の道具だった板を返すか、橋に組み込む許しを得る。
4. **古道の足跡**　水が引くたび古道に同じ足跡が現れる。足跡を精霊の残響として追うと、最後の一歩だけが岸に届かない。根につかまる縄を結び、残響が対岸まで歩くのを見届ける。
5. **跳ね橋の試歩**　根を踏めない荷獣のため折り畳み橋が試作される。歩く速さと踏面を変えて渡らせ、実用できる荷の重さと水位を札に書く。

### 月見の里

1. **池を暗くする夜**　水草の光が消え、祭りの中止が議論される。三日月壇で灯を覆って水路を観察し、灯を低い位置へ移すか、案内人の手灯だけで池辺を開く。
2. **月石の欠けた目盛り**　観測役の目盛りが月の位置と合わない。庭園跡と壇の影から台座の傾きを読み、観測具を戻して次の水草の光る夜を言い当てる。
3. **毎年違う一皿**　露店主が記憶を失った客へ毎年同じ料理を出す。観測役の記録の余白から客自身の昔の注文を見つけ、本人に今年の味を選んでもらう。
4. **池面を渡る火**　夜更けに灯が勝手に池を進む。岸から明暗を追うと水に落ちた祭り灯が精霊魚を浅瀬へ誘っている。灯を回収するか、魚のいる入り江まで誘導する。
5. **欠席の星図**　足を悪くした老観測役が坂を上れない。壇の観測を足元の印で継ぐか、池の映りを利用して低所に観測地点を作り、老役と新しい星図を描く。

### 雫葉の集落

1. **屋根を流れる水**　下段の菜園が干上がったと聞く。梯子で上段から樋をたどり、枯れ枝を除くか、新設の籠にも余り水を送れる分岐を修理する。
2. **梯子下の忘れ物**　水没期に舟が着く場所へ、毎朝同じ木彫りの鳥が流れる。樋から水を運ぶ小さな精霊の通り道を見つけ、彫り物の持ち主に返すか、精霊用に小さな代わりを置く。
3. **水の色を染める**　上段の染め手が流した水を下段が飲むのではと疑われる。雨桶と染め場を晴雨の日に見比べ、飲み水へつながる樋だけを切り離す。
4. **空の雨桶**　雨桶に穴が開き、共用修理が順番待ちになる。上段から桶を一つ借りるか、水運びを手伝って丈夫な葉で穴を塞ぎ、最後に返す水の量を当番と取り決める。
5. **舟の玄関**　水が深いと乗り降りできない住民に会う。舟と家の床の段差を測り、潮で上下する足場を試すか、水没時にも届く共用入口へ梯子を足す。

### 精霊樹の門前村

1. **封門から聞こえる声**　施療小屋に集まる証言が日ごとに変わる。根の複数地点で共鳴を聞くと、聞き手の記憶と一緒に反響していると分かる。声を公表せず門守と聞き取りの場を作るか、時間を限って巡礼者に開く。
2. **灯籠に残す道**　日暮れ前に灯籠の一つが消え、巡礼者が根を踏む。木漏れ日の残る安全な杭まで灯を移すか、木を照らさず足元だけ見える覆いを作る。
3. **口にしない名前**　施療を手伝うミナから、忘れた名を無理に呼び戻さないよう頼まれる。巡礼宿で手がかりを見つけても、本人に見せるかは意思を聞いてから決める。
4. **道を塞ぐ子鹿**　見回り道に横たわる角の透けた仔獣を見つける。精霊使いの前で鳴き方を比べ、休む根を守って道を迂回するか、夜に親の通り道へ案内する。
5. **夜の門の借り手**　門守から夜間用の札が一枚戻らないと聞く。札に掛けた草の匂いを追うと施療帰りの人が迷っている。足元灯を手渡し、次の夜に自力で歩ける道標を置く。

### 苔舟の町

1. **苔を剥がす前に**　堤に影響する浅瀬の浚渫を頼まれる。荷流し札と観測杭で泥が落ちる場所を絞り、狭い流路を掘るか浅い舟へ荷を載せ替える。
2. **まっすぐ漕げない舟**　修理した舟が右へ曲がる。岸と流れの両方で試乗し、櫂の形を揃えるか、船底の片側だけに厚い板を補う。
3. **舟庫で待つ精霊**　使わない丸木舟を割ると決まった途端、舟庫の苔が青く光る。精霊共鳴で昔の渡し守の声を聞き、舟を石堤の休み場に置くか、同じ木片を新しい舟に継ぐ。
4. **底に沈んだ荷札**　流水で荷札を失った配達人に会う。引き舟道をたどって濡れた箱の跡を探し、印と重さで送り主を見つけて受取人と引き合わせる。
5. **堤の上の昼休み**　堤の補修中に休憩所を使えなくなった舟子が集まる。養生畑を荒らさない座る場所を選び、日除けを貸す代わりに見回りを手伝ってもらう。

### 山桑の里

1. **桑に吹く風**　虫害を抑えたい畑組と蚕を守りたい糸場組が対立する。無被害の列と防風林を歩き、風を逃がす間引きか、被害の多い畝だけの手摘みを提案する。
2. **同じ橙が出ない**　祭り布の染め色が去年と違う。桑の丘と乾燥棚で染液の違いを試し、去年の色を再現するか、今年の色として返礼に出す。
3. **蚕の引っ越し**　糸場の屋根裏が暑くなり過ぎた。葉の水分と棚の風を調べ、蚕の箱を畑の近くへ移すか、日除けと通風口で工房内の温度を下げる。
4. **干し棚の手紙**　干し布に小さな糸文字が縫い込まれる。糸の結び方から作業場に伝わる符号と分かり、見習いが家族に伝えられなかった帰郷の知らせを届ける。
5. **帯を半分ずつ**　仲違いしている姉妹が同じ注文の帯を染める。仕上げの見本を持って往復し、合わせて一本にするか、色違いの二本として注文主と話をつける。

### 古枝の工房村

1. **生木の木口**　乾燥棚で生木の板を見かける。出荷印と防風林の切り株から荷を特定し、生木を抜いて分納するか、古材を補って納期を守る交渉へ進む。
2. **嵐が置いた材料**　雷で落ちた枝に精霊が寄り、刃を近づけると共鳴する。節の周りを避けて板を挽くか、枝を野外に戻して音の出る場所を森番と守る。
3. **手に合う鉋**　徒弟の手に合う鉋がなく、研ぎ直しの時間で遅れが出る。良い端材を探し、親方の握りを写すか、小さな手に合わせた治具を一緒に作る。
4. **大きすぎる荷車**　出荷道の橋が細く、大板が角でつかえる。丸太引き道で運べる支点を調べ、荷車を組み替えるか、買い手へ現地で組めるよう工房で先に加工すると申し出る。
5. **木屑の街道**　製材の木屑が雨で街道へ流れて滑る。水の溝を歩いて木屑を集め、苗床の保温材に回すか、修理工房で固めて焚き付けにする。

### 若芽の里

1. **古い木の新しい枝**　廃村の果樹を巡って若木畑の寄合が割れる。旧村で果樹の接ぎ目を調べ、枝を苗床に分けるか、森番と作業日を決めて現地で数本を管理する。
2. **葉屋根の前ぶれ**　風が吹く前に屋根の葉が一部ひっくり返る。若木畑で同じ葉の向きを調べ、雨を呼ぶ精霊の寄る木を見つけて洗濯当番と屋根直しの目安にする。
3. **苗床にない記念木**　移住を祝う木を贈った相手が再訪するが、贈り木は枯れている。苗床で残った芽を探して育て直すか、枯れた枝を刻んで記念札に変える。
4. **借りた畝の秋**　新住民が増え、作業の負担が以前の苗床組に偏る。若木畑の水運びに同行し、世帯の時間に合う当番表か、持ち場を近場にまとめる割り振りを試す。
5. **空き地の足音**　旧村行きの門で夜だけ足音がする。精霊の残響を追い、今では森になった井戸の位置を写すと、元住民が水桶を置いて引っ越しに区切りをつけられる。

## 蒼海の自由都市群リベルタ

### 潮待ちの港町

1. **深い岸壁は一つ**　穀物船と救難船で同じ岸壁を取り合う。干潮の水深を調べ、救難艇を別の岸壁から出すか、穀物を小舟に分けて優先枠を空ける。
2. **何も積まない帰り船**　船員の遺した荷札に帰帆だけが記される。船倉の空箱に残る擦れを調べると、乗船できない家族のために空の船で見送る習わしだと分かり、出港に立ち会える。
3. **夜番のクレーン**　無人の時間に青いクレーンが少しずつ回る。整備足場で風向きと荷台を調べると、波の力を蓄える古い装置が動いている。留め金を直すか、昼の計量台へ装置を移す。
4. **倉番の天気図**　読み書きの苦手な倉番が、絵で日々の波を描いてきた。潮見台で予報を試し、読み方を掲示に添えると、風待ちの船員も絵で出港を相談できる。
5. **出港までの一皿**　足止めされた船員への食事を頼まれる。倉ごとに違う余り物を集め、船へ温かいまま届けるか、次の航海に持つ保存食へ仕立てる。

### 帆布の市場街

1. **裂けたのは糸か布か**　試帆場に持ち込まれた帆の裂け目を調べる。縫い糸と出荷札で不良の巻きを絞れば、全部を禁売にせず事故の起きる帆だけ回収できる。
2. **天幕を張る朝**　大風で天幕が外れ、開市に間に合わない。店を回って使える支柱を借り、食品の区画から張るか、客が並ぶ風上の歩道を先に覆う。
3. **色を持たない帆**　家の紋章を外したい客が、縫い跡を隠せる職人を探す。見立てを頼み、紋に縛られない一色の帆か、家族から受け継ぎたい一部分を残す帆を注文する。
4. **お針子の乗船券**　船旅のため支度した若い縫い手が、修理依頼で出発できなくなる。店の共同購入で代役を払うか、当日分の依頼を引き継ぐ手順を工房に残す。
5. **旗のひらく方向**　流れの違う風に天幕の案内旗が巻き付き、客が同じ通路を回り続ける。屋根上の糸で向きを見て、旗の場所を変えるか地面に織布の標を敷く。

### 運河の船大工街

1. **壁の目地を読む**　弱った壁のある船渠で修理枠が足りない。水門時刻と歪みを調べ、安全な小開きで二組を入れるか、別の船台へ小漁船を引く。
2. **抜けない竜骨**　古船の一部を展示のため取り外した途端、船渠の水が逆巻く。精霊共鳴で船大工の掛け声を聞き、同じ手順で部材を収めて水を鎮める。
3. **君の最初の浸水**　徒弟が仕上げた小舟に水が入り、試験を隠そうとする。舟底に水が入る順を見守り、継ぎ目の補修と再試験の日程を本人が報告するのに付き添う。
4. **溺れない台車**　作業歩道の道具箱が運河に落ち続ける。台車の車幅と手すりの隙間を測って試作品を作り、船上でも使える軽量輪か歩道専用の固定輪を選ぶ。
5. **隣の船だけ鳴る**　係留した二隻の片方だけが夜に鳴く。潮が変わる時刻に張り綱の音を比べ、船腹の傷を治すか、泊まり方を変えて綱を緩める。

### 三潮灯台町

1. **いまはない信号**　岬に立って謎の合図を観測する。退役した灯台守が覚える救難符号を水先人に伝え、一夜だけ応答するか、沖の小舟へ別の灯を送る。フィーネが追う航路につながる。
2. **三本の流れの試験**　見習い水先人が潮の流れを言い誤る。西崖と岬端から浮標が流れる向きを一緒に見ると、凪と逆潮を見分けて試験をやり直せる。
3. **灯守の休暇**　交代できる者がいない灯台守が家族の祝いを諦める。救難詰所で信号の練習相手を募り、見回りまで任せるか、点灯だけ昼の班に引き継ぐ。
4. **暗礁が動いた日**　嵐のあとの岩影が地図と違う。崖の二地点で重なりを見て、別の岩に付いた古い標を直すか、暗礁の両端へ浮標を増やす。
5. **瓶の中の晩鐘**　光源の方角と合わない小さな響きを夜の岬で聞く。流れ着く瓶に音を閉じ込める波の精霊を見つけ、風裏の浜に瓶を置くと、夜番への時報が生まれる。

### 網干しの村

1. **網目一つぶん**　幼魚が混じる理由を、選別場で目の異なる網を試して確かめる。漁場を短期で休めて共同金庫を使うか、粗い網を全戸に貸し出して漁を続ける。
2. **干し網を盗む鳥**　修理済みの網が一部ずつ裂かれる。干し台の高所から海鳥の巣を見つけ、巣材用の短い縄を別の杭に結び直すと網に来なくなる。
3. **二軒の水揚げ祝い**　浜の合図が両家で重なり、違う客に宴を準備してしまう。作業を終えた漁師を順に訪ね、宴を一緒にするか山側と浜側で分ける。
4. **網針を持つ左手**　片腕を傷めた修繕屋が注文を返そうとする。舟大工から作業中に網を留めておける道具を借り、網針の形を工夫して小さな裂け目から取り組む。
5. **海獣の背の浮き玉**　沖に出た仔海獣の背に漁具が絡む。浜で好む魚と逃げ方を覚え、寄せ餌を使って網をほどくか、浅い産卵浜を避けて救難艇へ回す。

### 塩風の集落

1. **堤の赤い印**　地主が全区間の修理を根拠に値上げを求める。浸水杭と風車の分水を調べ、波をかぶる区間だけ先に直すか、休む塩田の借地料を一季免除する。
2. **塩の結晶晩餐**　加工した塩が苦いと保存食屋から返される。釜と塩田で別の採取時の塩を味見し、食用分を選り分けて残りを皮なめしへ売る。
3. **逆に回る風車**　無風の夜だけ風車が逆回転する。堤で砂を運ぶ小さな精霊の列を見つけ、水を汲む時刻をずらすか、砂が塩槽へ入らない覆いを架ける。
4. **塩蔵の足形**　倉の床に新しい足形が残り、盗難を疑う番人がいる。雨で膨らんだ木戸の隙間と採取跡を調べ、風が吹き込んだ塩の筋だと確かめる。
5. **畦越しの同窓会**　別々の田を管理する二人が風車の修理を機に再会する。お互いの収穫が終わる時間を畦づたいに確かめ、借りた風車で二人の最後の桶を同時に満たす。

### 碧帆の町

1. **保険帳の赤線**　護送契約を失った小舟の船長に会う。保険控えと修理札から難破と襲撃を分け、仲裁で寄港拒否を覆すか、小舟だけの保証率を取り決める。
2. **帆をあげない隊列**　船団の創立記念日に、帆を上げられない遺族の船が列から外される。埠頭で舟を曳ける船を募るか、倉庫前から上げる小旗で列に加える。
3. **保証人の署名**　独立した舵取りが初の契約を結ぶため保証人を探す。修理屋から仕事ぶりを聞き、少額の初荷を担うか、何人かで保証を分ける契約を用意する。
4. **海賊が残した茶箱**　共同倉庫で襲撃品とされた茶箱に合法取引の印がある。運河裏の仲裁所へ持ち込み、元の荷主へ戻すか、荷主の留守中に価格を保って共同で売る。
5. **帆に塗る碧**　碧い染料が足りず、遠便の同船確認が難しくなる。夕方に試帆し、小さな碧の帯でも見分けられる形か、染料を使わない旗の組合せを決める。

### 潮路の宿場

1. **橋を借りる時刻**　満潮前の通院と定期馬車が重なる。潮目盛りで旧石堤を見て徒歩客を案内するか、馬車の停車を一便ずつ分けるよう食堂の掲示に申し立てる。
2. **橋の中の花嫁**　潮が変わる前に婚礼の二組が橋の両岸へ着く。濡れる道を避けて客を集め、渡り切ってから祝うか、橋の屋根の下に空間を作って式を挙げる。
3. **潮が忘れた砂時計**　橋守の砂時計の時間よりも先に満潮が来る。旧石堤で動きを観察し、閉じ込められた水の精霊を浅瀬に返すと、潮は通常の速さに戻る。
4. **濡れた宿帳**　対岸へ届けた宿帳に海水が入り、客の予約が滲む。厩の預り札と食堂の人数控えから予約を再現し、木札で両宿に重複が出ない形を試す。
5. **旅立つ石積み屋**　橋の補修を終えた職人へ最後の食事を出したいと頼まれる。堤に残した目印を巡って教え子を呼び、橋の通れる時刻に食卓を整える。

### 小舟の里

1. **往診舟は誰のもの**　引き上げた遺品の舟の返還日が決まる。船底の継ぎ木を手がかりに代船を探すか、親族を冬の往診へ招いて春まで借りる話をまとめる。
2. **青い舟を塗り直す日**　船主になった子が先代の青を継ぐか迷う。舟棚を回り、別の家が残す塗り分けを見て、先代の印を水線に残すか新しい色で出す。
3. **浜通いの貝笛**　浅瀬の霧で笛の主が見えない。音の高低を追うと潮で迷った舟が分かる。舟揚げ浜から同じ節を吹き返し、干潮の斜路へ案内する。
4. **風にほどける舟結び**　同じ結びで並べた舟の一つが流される。舟棚と岬で波向きを観察し、舟の低い位置へ綱を通すか干潮の間だけ予備の縄を足す。
5. **波に眠る舟歌**　岬の老漁師が忘れた節を探している。沈み桟橋の廃村で櫂の音を波に重ね、精霊共鳴で聞けた一節を舟を直す住民に伝える。

### 燈魚の市

1. **灯を沈める売り手**　不漁で旧港の集魚灯を買う話が進む。競り前の漁区差を見て、灯を禁じて休漁するか、採取浜から離れた区画だけで短期の試験をする。
2. **競り値のない一籠**　値のつかない魚を漁師が捨てようとする。料理人と船員から必要な処理を聞き、干物にするか、閉市後に漁師自身が一皿として売れるよう場所を借りる。
3. **海図の空白を埋める**　航海具屋の海図では、灯台から見えない岩が抜けている。朝の岬と採取浜を歩いて角度を測り、干潮で歩ける道と暗礁の位置を別々の記号で記す。
4. **灯台の琥珀のかけら**　灯の欠片を集める拾い子が出店を追い出される。灯台守に古い破片の由来を聞き、欠けた覆いを直す材料と、拾い子が売れる飾り用を分ける。
5. **箱を開けた魚**　競り場の無人の箱が中から青く照る。航海具店の遮光布を使って光を抑え、箱ごと若い燈魚を採取浜の影へ放つと、後日群れが戻る。

## 機工連邦ヴァルカン

### 黒鉄港町

1. **積荷表より重い箱**　過熱したクレーンの機関番に声をかける。荷の刻印と計量を見比べ、評議会の再計量を求めるか、通常便を別の台へ移して危険な積込を一時止める。
2. **油が届かない歯**　小さいクレーンが朝だけ止まる。機関番の見回りに同行し、寒い朝に油が流れづらい箇所を温めるか、夜番用の給油道具を替える。
3. **船員待合の壁**　別々の言葉を話す船員が待合に座る。出港時刻と食事を絵札にして壁へ掛け、帰れない乗組員が炊事当番に加われるよう手配する。
4. **黒い小石の護符**　船出の護符売りが石の産地を答えられない。昔の船員待合で、漂着船の石を子が拾ったと知る。遺族のもとに返すか、由来を添えて船員の無事を祈る壁に置く。
5. **海へ消える熱**　温かい排水を好む甲殻獣が岸壁で荷役を妨げる。配管の熱が落ちる時刻を調べ、その間に小魚のいる湾へ誘うか、熱を離れた岩棚に回す。

### 歯車街

1. **まだ回る旧型**　新規格へ切り替える前に、旧型の修理横丁を訪ねる。試運転線で継ぎ手の危険箇所を見つけ、限定部品を共同旋盤で続けるか、改修費の積立を街区会に求める。
2. **歯車が隠す音**　組立工場の駆動音に混じって奇妙な節が響く。回転の遅い歯車を隔離して音を合わせると、かつての職人が組み込んだ仕事歌を直せる。
3. **盗まれた設計図の余白**　徒弟が図面を持ち出したと疑われる。規格試験場の借出札から許可を確認し、余白に本人が足した安全案を名前付きで審査してもらう。
4. **片手の旋盤番**　工具を握れなくなった旋盤番が最後の注文を断ろうとする。踏み板の支点を試し、見習いと二人の作業か、小部品の受付担当としての復帰を本人と選ぶ。
5. **刻を数える機械**　記憶を失った工房主が、歯車仕掛けの台で作業を覚え直す。工房を巡って工程札を集め、本人の手になじむ順に並べれば、最初の品を一人で仕上げられる。

### 赤炉工区

1. **勤務票の空白**　医務室で夜勤者の話が途切れる。勤務票の欠落とガルダの試作印を照合し、記録を伏せて検査を始めるか、職工会で名を隠したまま夜の搬出を止める。
2. **交代笛を取り戻す**　交代笛が聞こえない区画で残業が続く。排気廊に沿って音を試し、配管の共鳴を抑えるか、消灯の合図を通路の先にも増やす。
3. **炉辺の弁当**　家族に弁当を届けたい子が保守門で止められる。医務室と職工会所を回って安全な受け渡し台を探し、交代時間に待てる場所を設ける。
4. **赤い炉の青い炎**　試験炉の火が異常に青く、燃料担当が責められる。炉口と保管場で色の変化を記録し、持ち込まれた鉱屑を試すと、回収対象の燃料を限定できる。
5. **火花を食べる野良機**　放置された小型の清掃機が火花を追って炉群を走る。夜勤搬出口脇の保守棚から古い制御札を見つけ、炉に近づけず屑を集められる通路へ誘導する。

### 火口の見張り町

1. **閉じた避難路**　鉱区の運鉱車が避難路に停まり続ける。噴気を観測する地点を回って測候記録を確かめ、訓練で車両を移すか、待避庫から別の道を先に開く。
2. **灰の高さの背比べ**　見張り塔に去年より高い灰の印が見つかる。踊り場の日当たりを調べ、子が付けた背丈の印と判明したら、訓練の記録と別の柱を貸す。
3. **空の採取瓶**　採ったはずの噴気が試験前に抜ける。採取所と塔で瓶の温度を観察し、岩の熱で緩む古い蓋を見つけて交換する。
4. **熱を追う角獣**　本来冷たい斜面に角獣が集まっている。足跡と岩肌の温度を追うと、地中の温まりを見つけ、測候所へ新しい監視点として知らせられる。
5. **子のための避難鐘**　子守中に警報を聞き逃す家がある。谷の聞こえ方を調べ、窓側へ反射板を付けるか、隣の二軒と相互に戸を叩く当番を始める。

### 煤坂の村

1. **洗い水に残る煤**　職工寮が炊事煙の責任を問われる。夜勤口と灰受け場で採取し、炉煙と示す試料を無記名で提出するか、寮の退去要求に備えて居住組を先に集める。
2. **同じ煉瓦を運ぶ**　廃村の煉瓦が道の補修材として届く。道を直す組と旧家の遺族を案内して持ち主の印を見つけ、印のある数個だけを共同洗い場に移す。
3. **夜勤明けの絵描き**　寮の窓を汚す絵の具で若い絵描きが叱られる。共同洗い場から見える朝の光に合わせ、室内で描ける台を作るか坂上の壁を貸してもらう。
4. **雨樋で拾った星**　灰の中に光る石が詰まっている。丘の灰受け皿と各屋根を比べて空から降る場所を割り出し、記念に飾る分と工区に分析を頼む分を選ぶ。
5. **弔いの湯気**　旧村の知人を弔う一家が、共同洗い場で湯を分けてほしいと言う。夜勤帯の炊事番の分を確保しつつ、屋外の石鉢で火を据える場所を探す。

### 蒸気弁の集落

1. **二通りの枝管**　温室の苗が弱り、見回り番が古い図面を差し出す。保守溝の振動と低圧槽の目盛りで廃工場へ通う管を特定し、温室を低圧槽へつないでから枝だけを止める。
2. **朝だけ咲く温室**　まだ寝込む花の世話役が最初の開花を見たいという。弁の当番に蒸気を緩めてもらって遅く咲かせるか、花鉢を病室の窓へ届ける。
3. **一斉に鳴く弁**　子どもが蒸気の響きを楽器に真似ると、古い補助弁が同じ高さで応じる。番人の立会いで音を取り、調子の悪い弁の聞き分け表を作る。
4. **うちの苗ではない**　温室の鉢に、誰も植えていない種が芽吹く。散水の始まる方角を追って水路から入った種を見つけ、元の池へ戻すか低温の棚で観察する。
5. **白い通り道**　放熱でいつも霧が出る通りが、冬だけ白い壁になる。足元の温度を調べて霧を畑側に逃がすか、安全な見回り道と案内綱を作る。

### 鎚音の町

1. **夜の鎚を振る前に**　車輪の受注で療養所の夜が揺れる。音見台から鎚音が回る谷を確かめ、治具で昼の枠を増やすか、岩斜面側に遮音壁を試す。
2. **一打ちずつの共作**　耳の遠い鍛冶師と徒弟では、打つ合図が合わない。大鎚の外の練習台で手振りと足元の振動を試し、二人が失敗せずに農具を仕上げる合図を決める。
3. **曲がった車輪の里帰り**　車輪を返品した運送組の話と焼入れ帳が食い違う。荷役路の曲がり角と摩耗の向きから傷の理由を見つけ、鍛冶の修理か馬車道の切り返しを提案する。
4. **岩の向こうの太鼓**　休炉日に谷の反対から鎚音が返る。音見台と岩陰を巡って小さな岩の精霊を見つけ、休みの日の太鼓役に迎えるか元の谷へ返す。
5. **療養所に届く小鈴**　退所する子に、自分で鳴らす合図の鈴を作りたいと職人が願う。走る子の歩幅と手の力で音が分かるよう、金属片を削って本人と試す。

### 炉守の宿場

1. **積替駅に残った薬**　馬車の出発までに優先貨物の時刻表と厩の控えを調べる。薬を小口便で先に送るか、連邦の燃料貨物を動かさず積替の作業順を組み直す。
2. **煙突の火照り**　宿の煙突が暖炉を消した後も熱く、部屋で眠れない。屋根の点検口から駅の温風が逆流する箇所を見つけ、仕切りを付けるか共同浴場へ熱を回す。
3. **発車を知らせる靴音**　目の見えない旅人が列車の案内を聞き逃す。厩から待合までの足場と放送の響きを試し、音の違う誘導板か出発前に呼びに行く係を作る。
4. **忘れ物の工具箱**　預り期限を過ぎた箱に炉番の手書き印がある。宿帳と荷役の交代を照合し、近い工場に本人を訪ねるか、帰りの荷車に箱の到着を託す。
5. **一番遅い馬車**　最後の馬車番が列車に客を取られ落ち込む。山の聞き取りで列車が運びきれない小荷物を探し、定期の近距離便か希望日の集荷便を始める。

### 黄銅の工房村

1. **銘のない調圧器**　模造品とされた品を圧力試験室で調べる。検査係の記憶とガルダの試験記号が一致したら、安全に使える部品を残すか、旧式の来歴ごと提出する。
2. **時計の遅い家**　標準時計を合わせても、ある家の時計だけ正午に止まる。風の向きと小窓の熱を調べ、熱で伸びる針を交換するか、風通しのよい壁へ掛け直す。
3. **ばねを継ぐ姉妹**　別々の親方を目指す二人が同じばねの注文に応募する。荷重を変えながら強さとしなやかさを比べ、用途で分けるか二種類を一つの機械に合わせる。
4. **緊急鐘のからくり鳥**　標準時計の鳥が夜中に鳴り、炉の停止信号と間違えられる。工房裏から鳥の古いからくりを点検し、緊急鐘と重ならない時刻か音色を選ぶ。
5. **細工台の背丈**　小柄な見習いが資格試験で台に手が届かない。試験室の工具配置を測り、台を高低で選べるようにするか、足場と工具受けを試験規則に入れる。

### 黒曜の市場町

1. **品位の違う見本**　検定所の控えと旧魔鉱坑の見本から、公表された鉱区と実際の調達先を追う。商人会で連邦の契約を審査し直すか、再生材の買付枠を先に作る。
2. **火の粉を映す石**　飾り用の黒曜石に景色が一瞬遅れて映る。噴水と燃料市で光源を比べ、天墜ち後の熱が残る欠片と分かる。検定所に預けるか、広場で由来を添えて飾る。
3. **噴水に湯が戻る日**　休み場の温水が冷たくなった。廃熱樋を歩いて漏れを探し、燃料市の排熱を回すか、混み合う時間だけ湯を張るよう切り替える。
4. **小工房の競り札**　再生材の競りで大店が全てを買えるよう札を分けている。置場で使う量を聞き、最小の荷を小口で確保するか、小工房が共同で札を出せる仕組みを作る。
5. **見本棚に戻る石**　鉱夫が採った記念石を試料庫に寄贈する。どの坑道の物か古い見本で見比べ、採掘経路を家族に伝える展示か、次の探鉱者に役立つ地層の並びにする。
