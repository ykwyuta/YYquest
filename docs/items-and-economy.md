# アイテムと貨幣経済

アレンは、素材を集めて傷薬を調合し、余った素材で薬代と鍛冶の工賃を賄う。旅先で武器・防具・護符を選び、消耗する魔道具で危険な戦闘を切り抜ける。記憶を代償にする刻印魔法は店の取引から独立しており、貨幣や薬で失った記憶を買い戻すことはできない。

## 貨幣と取引

- **銀環**は環状列島の港で通用する共通貨幣。切り欠きのある輪形の銀貨で、船荷の受け渡しに使われて広まった。財布はアレン一行で共有する。初期所持は24銀環と灰葉の傷薬2個。
- ノクスのサイドストーリーは解決時に12銀環を一度支払う。弱い魔獣の初討伐は9銀環と魔獣のなめし革、強い魔獣の初討伐は14銀環と残響の欠片を得る。強弱の境界は最大HP20。
- 霧灯の港町の荷揚げ桟橋、西風の砦町の護送受付と市、灰石の市の南の河原市で取引できる。店は定価で販売し、素材は基準価格の半額で買い取る。残響の欠片は買い取りだけ扱う。
- 所持金は回復薬と魔道具の購入、旅籠、調薬と鍛冶の工賃に使う。冒頭の水門と石碑、ノクスの本筋、港からの出航に支払いは要らない。
- 素材と消耗品は品目ごとに99個まで。製作装備は各1点を所持でき、武器・胴防具・護符を1つずつ装備する。武器を替えても父の大剣は荷袋に残る。所持上限や素材・銀環の不足で取引が成立しないときは、銀環も素材も減らない。

## 回復手段と消耗する魔道具

| 品名・施設 | 効果 | 入手・料金 |
| --- | --- | --- |
| 灰葉の傷薬 | HPを8回復 | 10銀環。灰葉草2個で調合もできる。工賃無料 |
| 苦霧の煎じ薬 | HPを16回復 | 22銀環。灰葉草1個と苦霧根2個、工賃4銀環で調合もできる |
| 火花筒 | 敵に12ダメージ。使用後に消費 | 24銀環。沼鉄鉱1個と残響の欠片1個、工賃6銀環で製作もできる |
| 共同炉の手当て | HPを全回復 | 灰灯りの村の共同炉で無料 |
| 診療所の手当て | HPを全回復 | 谷守の村の南岸の診療所で無料 |
| 旅籠で休む | HPを全回復 | 遠火の宿場の灯火旅籠で8銀環 |

調薬は灰灯りの村の炉の炊事場で行う。薬は島の荷袋から使うか、戦闘で「道具」を選んで使う。戦闘での使用は1ターンを使い、敵が生きていれば反撃を受ける。HP満タンでは薬を消費しない。HPは島での戦闘をまたいで残り、倒れた場合は港に戻って全快する。物語冒頭のHPとチュートリアルの戦闘は、島探索のHP・装備から独立している。

## ドワーフ鍛冶

石継ぎの町の石工場に、ヴァルカンから出張しているドワーフ鍛冶師ブロムがいる。石工にはたがねを直し、旅人には採集品と工賃で武具を打つ。注文画面で手持ちと必要数を確認し、完成品は荷袋から装備する。工房画面で右を押すと荷袋を開ける。

| 武器・防具・護符 | 効果 | 必要な素材 | 工賃 |
| --- | --- | --- | --- |
| 父の錆びた大剣 | 通常攻撃6 | 最初から装備 | — |
| 沼鉄の片手剣 | 通常攻撃8 | 沼鉄鉱2、灰樹の枝1 | 18銀環 |
| 残響鋼の剣 | 通常攻撃10 | 沼鉄鉱3、残響の欠片2 | 42銀環 |
| 革の旅装 | 反撃ダメージを1軽減 | 魔獣のなめし革2、灰樹の枝1 | 12銀環 |
| 鋲留めの胴鎧 | 反撃ダメージを2軽減 | 沼鉄鉱2、魔獣のなめし革2 | 26銀環 |
| 霧灯の護符 | 反撃ダメージを1軽減。胴防具と併用可 | 灰樹の枝1、残響の欠片1 | 16銀環 |

防具と護符を併用しても反撃の最低ダメージは1。鍛冶で強化するのは通常攻撃と耐久力で、刻印魔法と精霊共鳴の威力は装備で上昇しない。
