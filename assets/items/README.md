# アイテムのアイコン

組み込み ImageGen で15品目を一枚ずつ生成しました。持ち物・戦闘道具・売買・調薬・鍛冶で使います。マップにある灰葉草、苦霧根、灰樹の枝、沼鉄鉱にも同じ絵を使います。

## 共通プロンプト

> Create one production inventory icon for a painterly high-fantasy Japanese RPG, watercolor/gouache texture and clear broad silhouette at 24 pixels, slightly top-down three-quarter view, soft warm light from upper left, rich midtones and strong readable light-dark separation. Center one isolated full object on a truly transparent alpha background, square canvas, fill around 76% of the image, leave wide empty gutters, no crop. No text, no letters, no frame, no scenery, no cast shadow or backdrop, no other objects. Hand-painted with clean edges rather than pixel art.
